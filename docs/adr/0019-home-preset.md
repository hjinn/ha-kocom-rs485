# ADR-0019: 프리셋 `none` 대신 `home`(재실)

- 상태: 승인 (2026-10-22)
- 대체: ADR-0016의 프리셋 표 (`none`, `away`)

## 맥락
사용자가 꺼짐 / 난방 / 외출을 하나의 모드로 고르기를 원했다. HA의 `hvac_mode`는 HA가 정한 값(`off`, `heat`, …)만 쓸 수 있어 외출을 넣을 수 없고, 꺼짐은 `hvac_mode`에만 둘 수 있다. 프리셋 이름은 integration이 정할 수 있다.

## 결정
| 상태 | `hvac_mode` | `preset_mode` |
|---|---|---|
| 꺼짐 | `off` | 없음 (`None`) |
| 난방 | `heat` | `home` |
| 외출 | `heat` | `away` |

- `preset_modes`: `home`, `away`. 화면 표시는 integration 번역으로 고정: 재실 / 외출, Home / Away.
- `home` 선택: 마지막 난방 설정 온도로 난방 (꺼진 방에서도 켜짐). 이전 `none`과 같은 동작.
- 꺼짐일 때 프리셋을 비우는 이유: 꺼진 방은 재실도 외출도 아니다. 설정 온도를 비우는 것과 같은 규칙.

## 결과
- 자동화에서 `preset_mode: none`을 쓰던 경우 `home`으로 바꿔야 한다 (v0.1.0 이후 변경).
- 세 상태를 한 곳에서 고르는 것은 대시보드 구성이나 별도 select 엔티티로 다룬다 (미결정).
