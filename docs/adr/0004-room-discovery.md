# ADR-0004: Room은 설치 시 자동 탐지, 실패 시 수동 선택

- 상태: 승인 (2026-10-21)

## 결정
config flow에서 EW11 host/port 입력 후:
1. Thermo `00`~`03`에 query를 순차 송신, 응답한 Room을 탐지 결과로 삼는다.
2. 탐지 결과를 체크박스(미리 체크됨)로 보여주고 사용자가 확인·수정한다.
3. 응답이 하나도 없으면 4개 Room 체크박스를 비어 있는 상태로 보여주는 수동 선택(C)으로 넘어간다.

Room 기본 이름: `00` 거실, `01` 안방, `02` 방1, `03` 방2. 엔티티 이름은 HA에서 변경 가능.

## 근거
HACS 공개 배포 대상이므로 집마다 Room 구성이 다르다. 고정 4개는 응답 없는 엔티티를 만든다.
탐지 query는 연결 테스트 역할도 겸한다.
