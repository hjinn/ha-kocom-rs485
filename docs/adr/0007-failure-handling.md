# ADR-0007: 장애 처리와 가용성(availability)

- 상태: 승인 (2026-10-21)

## 결정
| 상황 | 동작 |
|---|---|
| EW11 TCP 연결 끊김 | 모든 Room 엔티티 `unavailable`. 재연결 백오프 5→10→30→60초(이후 60초 고정). 재연결 시 즉시 전체 query. |
| Room 무응답 | Polling 2회 연속 무응답 시 해당 Room만 `unavailable`. 감청 패킷 수신 시 즉시 복구. |
| 명령 실패 (seq 4회 재전송 후 ACK 없음) | `HomeAssistantError` 발생 → UI 실패 알림. 낙관적 상태 변경 없음(실제 응답 수신 후에만 반영). 소켓은 닫지 않음. |
| 동시 명령 | 송신을 단일 큐로 직렬화 (참조 구현 `send_lock`). |

## 근거
참조 구현은 ACK 실패 시 소켓을 닫고 재연결한다. 그러나 연결이 살아 있는 상태의 ACK 실패는 대개 버스 충돌이며 연결 문제가 아니므로, 재연결은 불필요한 공백만 만든다.
