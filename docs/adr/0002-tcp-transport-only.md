# ADR-0002: EW11 연결은 TCP 소켓만 지원 (MQTT 모드 미지원)

- 상태: 승인 (2026-10-21)

## 맥락
EW11은 TCP 서버 모드와 MQTT 클라이언트 모드를 모두 제공한다. MQTT 모드는 다중 구독(버스 모니터링), 브로커 측 재연결 흡수라는 장점이 있다.

## 결정
v1은 TCP 소켓만 지원한다. 전송은 `Transport` 인터페이스 뒤로 분리해 이후 MQTT 전송을 프로토콜 코드 변경 없이 추가할 수 있게 둔다.

## 근거
- EW11 MQTT는 시리얼 바이트를 gap time/버퍼 기준으로 끊어 보내므로 21바이트 프레임 경계가 보장되지 않는다 → 재조립 로직이 어차피 필요.
- 브로커 홉이 추가되어 쓰기 타이밍(마지막 수신 후 30ms 대기) 제어가 부정확해져 버스 충돌 위험이 커진다.
- Mosquitto와 HA MQTT integration에 대한 런타임 의존이 생긴다.
- 원본 kocom.py는 TCP로만 장기 운용 검증되었다.
