# ADR-0005: Thermo → climate 엔티티 매핑, 외출은 읽기 전용

- 상태: 일부 ADR-0016으로 대체됨 (2026-10-21) — 외출 표현만. 온도 범위·켤 때 설정 온도 규칙은 유효

## 결정
- `hvac_modes`: `off`, `heat` (값 바이트 0: `11`=heat, `01`=off)
- 외출(Away)은 상태 속성(attribute)으로만 노출한다. preset 제어는 제공하지 않는다.
- heat 전환 시 설정 온도: 마지막으로 관측한 설정 온도, 없으면 23℃.
- 온도 범위 5~40℃, 1℃ 단위 (실기기 허용 범위 확인 필요).

## 근거
참조 구현은 away 바이트를 읽기만 하고 송신한 적이 없다. 검증되지 않은 송신 패킷을 실제 월패드에 보내지 않는다.
월패드에서 외출 설정 시 패킷을 캡처해 송신 형식이 확인되면 preset `away`로 확장한다.

참조 구현은 heat 전환 시 항상 설정 파일의 `init_temp`를 보내 사용자가 마지막으로 설정한 온도를 덮어썼다. 이를 바로잡는다.
